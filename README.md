# 🔍 Inspector Management Platform

A management platform for inspectors with multilingual support (Arabic/English), profile management, and examination pages.

## Features

- **Inspector Profiles** — avatar uploads with normalized URL handling
- **Examination Pages** — manual and public examination views with image rendering
- **Multilingual** — Arabic/English i18n labels
- **Role-based Access** — inspector and admin roles

## Tech Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** Laravel
- **Storage:** Public uploads via samh.store

## Setup

```bash
npm install && npm run dev
composer install && php artisan migrate
```
